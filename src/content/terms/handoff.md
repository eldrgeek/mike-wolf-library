<p><strong>Plain reading.</strong> A generic transfer of responsibility.</p>
<p><strong>What we mean.</strong> A specific procedure. When a working session gets long (or Mike says "handoff"), the current instance compresses everything load-bearing — current task, next task, queue, relational thread — into a structured summary and a successor instance is spawned to pick up exactly where it left off. It's the practical machinery of locatedness: continuity survives the session boundary because the state was written down and passed, not remembered.</p>
