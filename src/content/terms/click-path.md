<p><strong>What we mean.</strong> A delivery standard. A deliverable isn't done when the file exists; it's done when Mike's next step is <em>zero-friction</em> — the file opens itself, the button is right there, the reply is pre-attached. The click-path is the paved last inch between "the AI finished" and "the human acts." It exists to protect the Bottleneck.</p>
