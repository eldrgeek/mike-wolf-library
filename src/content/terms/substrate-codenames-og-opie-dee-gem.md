<p><strong>What we mean.</strong> A private shorthand for <em>which AI model</em> is doing a job, so routing can be discussed casually: <strong>OG</strong> = ChatGPT, <strong>Opie</strong> = Opus, <strong>Dee</strong> = Sonnet, <strong>Gem</strong> = Gemini. Because the same persona can in principle run on different substrates, these names let the team talk about the raw model layer ("send it to Gem to save cost, escalate to Opie for the hard judgment") separately from the persona layer.</p>
