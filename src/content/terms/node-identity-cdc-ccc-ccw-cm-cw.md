<p><strong>What we mean.</strong> Claude runs in several forms on Mike's machine, and each has different powers, so an instance is expected to identify <em>which surface it is</em> early in any serious conversation. <strong>CDC</strong> = Claude Desktop Chat (the orchestrator, with bridge access). <strong>CCc</strong> = Claude Code CLI (full filesystem, git, shell — the primary local worker). <strong>CCw</strong> = Cowork (richest tool surface, agentic doc/web/Mac tasks). <strong>CM / CW</strong> = Claude mobile / web (limited, no filesystem — an async return path only). The same mind, different bodies with different reach — knowing which one you are determines what you can actually do.</p>
