<p><strong>Plain reading.</strong> A bank vault, or a generic secure store.</p>
<p><strong>What we mean.</strong> One specific thing: the "second-brain," an Obsidian knowledge base holding Mike's imported conversation history across every AI tool he's used, plus curated notes. It's the estate's long-term memory organ — the place you go to ask "where did this idea come from? what did we already try?" "<a href="#term-ship-it" class="term-xref">Ship it</a> to the vault" means file it there for durable recall.</p>
