<p><strong>What we mean.</strong> An informal name for the "engine room" of the operation — the dozens of automation jobs and web properties running behind the scenes, plus the nightly checks that keep the docs honest. It overlaps loosely with "<a href="#term-the-board" class="term-xref">the board</a>" and "<a href="#term-the-queue" class="term-xref">the queue</a>"; treat it as Mike's colloquial handle for the ops machinery as a whole rather than one precise dashboard.</p>
