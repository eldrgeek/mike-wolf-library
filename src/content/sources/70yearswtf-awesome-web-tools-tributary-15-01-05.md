Today I found another awesome web tool: [tributary.io](http://tributary.io/). Tributary describes itself thusly:

> Tributary is an experimental environment for **rapidly prototyping visualization code**. The environment provides several useful libraries, as well as a simple interface for live code editing

That bunch of words that don't begin to reveal its awesomeness (neither do these, either.) And even using it doesn't reveal it, though it gives a hint.

To see how awesome it is you've got to watch [these videos](http://enjalot.github.io/dot-enter/) where the person behind Tributary: [+Ian Johnson](https://plus.google.com/112153365286725889851) aka @enjalot who uses it to help you understand 3d.js, another really awesome web tool.

Here's his site: [http://enja.org/](http://enja.org/) where he's posted some of the other cool things that he's done.

He's not alone in building Tributary:

[Contributors](https://github.com/enjalot/tributary/graphs/contributors) include [bollig](https://github.com/bollig), [ejfox](https://github.com/ejfox), [roundrobin](https://github.com/roundrobin), and[georules](https://github.com/georules/).
