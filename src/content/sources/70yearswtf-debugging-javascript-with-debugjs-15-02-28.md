I'm obsessed with creating the world's most awesome web development environment. Part of what I'm aiming for is resident in tributary.io, which I blogged about [here](http://70yearsoldwtf.blogspot.com/2015/01/awesome-web-tools-tributary.html). Now another piece in the puzzle that I'm trying to put together is this project: [https://github.com/amasad/debugjs](https://github.com/amasad/debugjs).

DebugJS uses a clever hack on the feature called "[generators](https://developer.mozilla.org/en-US/docs/Web/JavaScript/Reference/Statements/function*)" that's in the new version of Javascript (ES6).

You probably don't care about this, but if you did, [here](http://amasad.me/2014/01/06/building-an-in-browser-javascript-vm-and-debugger-using-generators/)'s more than you'd ever want to know about generators, and how to build a VM using them. And [here](http://amasad.me/2014/01/06/building-an-in-browser-javascript-vm-and-debugger-using-generators/)'s the payoff: a Bret-Victor-style example using debugjs.

Of course I'm still waiting for Bret to open source the great technology he's used.
